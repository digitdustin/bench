Rules

Do

  • Start from a template and run build.mjs, so the CSS goes in word for word
  • Put every image or chart in a plate with its corner labels
  • Open every page with the masthead: eyebrow, headline, lede, details row
  • Write labels, headers and buttons in sentence case
  • Use green and red only for YES/NO and up/down
  • Add a token in tokens.css and log it here when a new value is needed

Don't

  • Use all caps, letter-spaced labels or mono for numbers in text
  • Add web fonts, emoji, or icons from any set but Nucleo
  • Use a brand accent for emphasis; use weight and the strong ink
  • Use more than one display headline per page
  • Write a color, font or radius into page CSS; check.mjs fails it
Changelog
  1. v1.9, Nov 8. Media cards: a picture in a card runs to the card's edges and the card's corners clip it. Only the text under it is padded, and a length or type tag sits on the picture's bottom-left corner.
  2. v1.4, Oct 16. A 2D mockup kit for web and mobile flows: phone and browser frames built from small parts, skeleton lines for text that doesn't matter, one lit element per screen, and wires from the tapped element to the next screen. The same wires join nodes in system diagrams. See Suggest a Feature Flows for the full set.
  3. v1.3, Oct 16. Pages declare a read (780) or wide (1080) width, and single wide blocks in a read page break out. Tables whose rows wrap to several lines stripe every other row faintly in place of row lines.
  4. v1.1, Oct 15. Vertical tabs for reference sections with four or more topics: questions in a quiet list on the left with a sliding raised highlight, one answer panel on the right.
  5. v1.0, Oct 15. Progress uses the Polymarket Slack status reactions (to do, underway, partly done, on hold, done, canceled, aligned), with the neutral ones inverted per theme. A condensed figure-numeral face for big numbers inside interactive figures. Choice lists are one connected box that stretches to the figure beside it.
  6. v0.9, Oct 15. Stats that describe a chart share its box, split by a dashed line. Boxes side by side are always the same height: charts center, text panels pin their source to the bottom, and captions move inside the plate.
  7. v0.8.1, Oct 15. Stats are one block with a ring around it and dashed dividers between cells.
  8. v0.8, Oct 15. Stat cards align part by part across a row. Chips that show a level or status always carry a dot. Card tags such as Recommended sit centered on the card edge, outlined like the selected card. Added pieces for interactive pages: four chart series colors (pending approval), selectable cards, a disclosure, a range slider and checkbox, table cell tones, code colors, and runtime carets for page scripts.
  9. v0.7, Oct 15. Every page gets a light and dark toggle, fixed top right: a pill-shaped segmented control with filled 12px Nucleo icons (sun, moon). It follows the system until the viewer picks, then remembers the choice in that browser.
  10. v0.6.1, Oct 15. Padding scales with the box: 24px for a panel that spans the full column, 16px for cards that share a row.
  11. v0.6, Oct 15. Up and down changes always use a filled Nucleo caret, which the build adds to every change marked up or down. Icon size follows the text beside it: the 12 grid for text up to 13px, the 18 grid at 16px for body text, buttons and tabs, and 18px beside headings and big numbers. Filled icons show a state, outline icons are for actions and objects.
  12. v0.5.2, Oct 15. The page date is always the last item in the eyebrow, and the build checks for it.
  13. v0.5.1, Oct 15. Panels and stat tiles padded 16px all round, with 8px between parts. Connectors show logos only, with the name on hover.
  14. v0.5, Oct 15. One border color for every container and control (a new ring token); line tokens are now only for dividers inside a container. Tighter heading groups: 4px from label to heading, 6px to the description, 16px to the content. The details row stays on one line, scrolls sideways with a fade when it overflows, and can end with a Connectors field showing the logos of the MCPs a page drew on.
  15. v0.4, Oct 15. Skill restructured: scripts/, four layout templates, a component cookbook and a chart guide; build runs the drift check and rejects leftover placeholders. Added from the 5-minute memo trial: amber signal for partial or in progress, hollow chip for unknown, numbered rows, table group rows and stacked status cells, a selected panel, bar chart marks with a hatch for partial periods. Fixed captions breaking inline code onto its own line, and stat values not lining up when a label wraps. Segmented control track lost its outer ring.
  16. v0.3, Oct 15. Buttons get a lit top edge and soft drop in both themes, primary and secondary. Stat tiles drop the small grey unit; units sit inline at full size, and changes get Nucleo arrows. Tables follow Medusa: no enclosure, a tinted header band ruled top and bottom, 48px rows. Headline down to 40px and the masthead is now a fixed format. An Author field with avatar is added to every details row automatically. The segmented control has a sliding thumb. All icons come from Nucleo.
  17. v0.2, Oct 15. Took labels, tables, controls and shape from Linear. Uppercase mono labels replaced by sentence-case sans. Stat numbers and table figures in sans with even-width digits. Tables get quiet headers and a rounded container. Soft radii (4/6/8/12), lighter borders, pill chips colored by their dot. Muted text darkened for legibility. Spread gauge replaced by a plain chart plate.
  18. v0.1, Oct 15. First cut from Market Press: palette, mono labels, square plates, 52px headline.
